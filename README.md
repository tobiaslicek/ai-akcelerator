# AI akcelerátor

Osobní ranní aplikace pro učení AI. Běží jako Claude Artifact: https://claude.ai/artifact/788QXdgtE75gkvDaXc7aYE

- **Dnes:** otáčkoměr tří ranních kroků, brief novinek z AI, výzva týdne
- **Učit se:** lektor, kontrolní otázky, zápisník
- **Trasa:** 29 témat v šesti etapách s opakováním po dni, týdnu a měsíci
- **Knihovna:** videa a kurzy na později
- **Systémy:** deník vlastních skillů, automatizací a appek

`index.html` je zdroj stránky artifactu. Data (brief, postup, knihovna, systémy) nejsou v repozitáři, drží je databáze artifactu. Lektor, čtení nahlas a diktování fungují jen při otevření v Claude.
